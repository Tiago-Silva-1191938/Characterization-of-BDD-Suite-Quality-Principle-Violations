# Characterisation of BDD Suite Quality-Principle Violations in Open-Source Cucumber/Java Projects

Project repository for the MSc dissertation of Tiago Silva (ISEP, MEI).
It keeps the records of the work under version control.
The commit history shows when each decision was made.

## Status
Private during the work.
At the end it is made public and archived with a DOI.

## Layout
| Folder | Content |
|---|---|
| `protocol/` | Literature review protocol, with a dated change log |
| `review/searches/` | Search log and the records exported from each source |
| `review/` | Screening sheet, extraction table and snowballing log |
| `tool_survey/` | Comparison table of the tools for analysing Gherkin specifications |
| `codebook/` | Operational definitions of the principles, with examples (later) |
| `code/` | Detection and history-mining code (later) |
| `data/` | Pseudonymised mined data and labels (later) |
| `analysis/` | Analysis scripts for RQ1 to RQ3 (later) |

## Data protection
Mined data enters this repository only after pseudonymisation.
Contributor names and e-mail addresses are never committed.
The correspondence table between identities and pseudonyms is kept outside the repository.
